# Engineering Unit Converter

## What it does
This is a simple Python program that converts different engineering units. It can convert length, temperature, weight and speed in different directions.

## How to run it
Install Python 3, then run:

python engineering_unit_converter.py

## Sample output
ENGINEERING UNIT CONVERTER
1. Length Conversion
2. Temperature Conversion
3. Weight Conversion
4. Speed Conversion
5. View History
6. Exit

Choose an option: 1
Choose conversion: 1
Enter value: 1000
Answer: 39.37 inches

## My own twist
I added a conversion history feature that allows users to view previous conversion activities.
